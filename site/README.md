# PUFF Soft Lab

An original soft-object interaction demo inspired by the idea of tactile web toys.

- Pure HTML / CSS / JavaScript
- Canvas-based squishy character
- Squish / stretch / tickle / toss interactions
- Color, softness and size settings
- Sound toggle
- Collectible card generator
- GitHub Pages deployment workflow

This implementation does **not** copy the source code or image assets of `estherliu-lab/momo-soft-play`.

The published site is built from the `site/` directory.
